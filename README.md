# StreamNest

StreamNest is a planned Nuvio plugin for movies and series.

## Planned scope

- Movie and series integrations from sources selected after technical evaluation.
- Xtream video-on-demand (VOD) access using a user-provided server URL, username, and password.
- Movies and series only, including over Xtream. Live TV is outside the project scope.

## Status

The project is in initial planning. No installable plugin is available yet, and
sources have not been selected.

Source evaluation will cover accessibility and bot protection, search and metadata
parsing, season and episode matching, stream resolution, and compatibility with
Nuvio's plugin runtime. Support for Xtream configuration and playback must also be
verified against Nuvio's plugin interface before implementation.
